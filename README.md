📍 CeliRadar – README 
Bienvenido al README del proyecto CeliRadar, una aplicación web creada para acompañar a personas celíacas y facilitar su vida diaria mediante información confiable, accesible y actualizada.

🧩 ¿Qué es CeliRadar?
CeliRadar es una app que permite:
Encontrar tiendas, cafés y restaurantes sin TACC en un mapa interactivo.


Acceder a recetas sin gluten, clasificadas por categorías.


Que usuarios suscritos puedan agregar, editar y eliminar sus propias recetas.


Consultar consejos y guías sobre cocina sin TACC.


Dejar comentarios en los comercios.


Está pensada para ayudar a personas celíacas a encontrar opciones seguras y a cocinar sin gluten con tranquilidad.

🚀 Funcionalidades principales
🔐 Autenticación y Suscripción
Registro e inicio de sesión.


Validación de email.


Acceso al mapa para todos.


Acceso a recetas y comentarios solo para suscriptores.





🗺️ Mapa interactivo
Implementado con Leaflet.


Muestra comercios sin TACC (tiendas, bares, restaurantes).


Cada marcador contiene descripción, fotos y comentarios.


🥗 Recetas sin TACC
Accesibles solo para usuarios suscritos.


Clasificadas por categorías:


Panes


Pastas


Tortas y dulces


Masas



Carrusel visual para elegir categoría.


Recetas subidas por usuarios incluyen el nombre del suscriptor.


Cada usuario puede editar solo sus recetas.



📱 Interfaz general
Responsive.


Menú para navegación.


Logo de la app.


Estética simple y limpia.






🧱 Tecnologías utilizadas
Frontend: React (Vite), HTML, CSS, JavaScript


Backend: NestJS


Base de datos: MySQL (Clever Cloud)


Despliegue Backend: Render


Despliegue Frontend: Firebase


Mapas: Leaflet
